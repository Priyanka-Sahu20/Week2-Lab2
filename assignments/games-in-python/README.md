
# 🎮 Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game where players guess letters to reveal a hidden word before running out of attempts. You'll practice string manipulation, loops, conditionals, and working with lists in Python.

## 📝 Tasks

### 🛠️ Build the Hangman Game Logic

#### Description
Create the core game logic that manages word selection, tracks guessed letters, and determines win/lose conditions. Your game should randomly select words from a list and maintain the game state throughout play.

#### Requirements
Your game must:

- Randomly select words from a predefined list
- Track guessed letters and incorrect guesses
- Display current progress using underscore format (e.g., `_ _ _ _`)
- Check if guesses are correct and update game state
- Determine when the word is completely guessed or attempts are exhausted

### 🛠️ Implement Game Flow and User Interaction

#### Description
Build the interactive game loop that accepts player input, provides feedback, and manages the overall game experience from start to finish.

#### Requirements
Your game must:

- Accept letter guesses from the player
- Validate input (single letters only)
- Display remaining incorrect guesses at each turn
- Show win/lose messages with appropriate outcome
- Ask the player if they want to play again
